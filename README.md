# EchoMind

A web-based cognitive memory training application built as an undergraduate thesis project for the Department of Informatics, Ionian University.

---

## Requirements

**PHP 7.4+**
**MariaDB 10.2+**
**Apache**

---

## Installation

### 1. Install XAMPP

Download from [apachefriends.org](https://www.apachefriends.org/) and install it.
### 2. Place the project

Copy the project folder into your web root so the final path is:

```
C:\xampp\htdocs\echomind\
```

On macOS/Linux this is usually `/Applications/XAMPP/htdocs/echomind/` or
`/opt/lampp/htdocs/echomind/`.

Or clone it directly:

```bash
cd C:\xampp\htdocs
git clone https://github.com/LenaDh7/Echomind.git echomind
```

### 3. Start Apache and MySQL

Open the **XAMPP Control Panel** and press **Start** next to both **Apache** and **MySQL**.

### 4. Open the app

```
http://localhost/echomind/
```
